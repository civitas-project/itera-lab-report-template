## Aturan penulisan

1. Aturan turunan variabel berasal dari PDF modul praktikum.
2. Nilai variabel diambil dari NIM mahasiswa dalam `profile.toml`.
3. Sumber variabel harus mencantumkan seksi PDF modul tempat aturan ditulis.
4. Status variabel adalah `go` (atur dan nilai jelas dari PDF) atau `ragu` (PDF tidak menentukan, tanyakan manusia, jangan tebak).
5. Pemrograman berorientasi objek TIDAK menggunakan rumus subnet atau VLSM; tidak ada variabel jaringan yang diturunkan dari NIM dengan subnet mask.
